# BINOVA — صفحة التحقق من المستندات

الصفحة اللي بتفتح لما حد يمسح كود QR على إذن مطبوع من BINOVA WMS.
بيانات الإذن جوه الرابط نفسه وموقّعة رقميًا، والصفحة بتتأكد من التوقيع على الموبايل. مفيش بيانات سرية هنا.

- `index.html` الصفحة
- `keys.js` الشركات المسجلة (مفاتيح عامة بس)
- `fonts/` IBM Plex Sans Arabic (رخصة OFL)

إضافة شركة: البرنامج ← الإعدادات ← الطباعة ← أكواد ISO والتوقيعات ← "صفحة التحقق بالموبايل"، وبعدين حط السطر اللي بيطلع في `keys.js`.
